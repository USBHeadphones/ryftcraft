# Ryftcraft
Ryftcraft is comparable to Minecraft v1.19.2, and has support for shaders, skins, resource packs, data packs, as well as custom music. (mods are like 85% done, but I'm leaving for 2 years so just suffer i guess :P)

Build from a custom engine named Ryft™(not really trademarked, but pls don't yoink my idea), this build allows for accurate Minecraft ADJACENT* gameplay, with multiplayer lan lobbies, and all gamemodes.

#RYFTCRAFT DOES NOT COME WITH TEXTURE PACKS!!!!
on first startup, you will be required to upload a 1.19.2 compatible texture pack in order to play the game.

Similarly, no audio is included, so you will need to create a music pack ingame(its super easy, just download some songs, then the game will format it into a zip when you select the files and create a music pack).






*Adjacent here meaning exactly the same for all intents and purposes, but still legally distinct.
